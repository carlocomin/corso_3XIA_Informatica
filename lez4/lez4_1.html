Lezione 4.1 — Cicli WHILE e DO

Obiettivo: progettare cicli che terminano, distinguendo il controllo prima del corpo da quello successivo al corpo.

Quando serve un ciclo?

Un ciclo ripete un gruppo di istruzioni mentre una condizione lo richiede. È utile quando il numero di ripetizioni dipende dai dati o dallo stato raggiunto durante l'esecuzione.

  • Inizializzazione: prepara contatori, accumulatori e altri valori.
  • Condizione: decide se eseguire o ripetere il corpo.
  • Corpo: contiene il lavoro da ripetere.
  • Aggiornamento: modifica lo stato e avvicina il ciclo alla conclusione.

Se le variabili della condizione non cambiano nel modo previsto, il ciclo può non terminare.

Due controlli in posizioni diverse

StrutturaQuando controllaIterazioni minimeSignificato della condizione
WHILEPrima del corpo0Continua mentre la condizione è True.
DO di FlowgorithmDopo il corpo1Ripete mentre la condizione è True.
REPEAT-UNTIL in altro pseudocodiceDopo il corpo1Ripete finché la condizione di uscita è False.

Attenzione alla negazione: do ... while nonValido e repeat ... until valido descrivono lo stesso comportamento, ma le condizioni hanno significato opposto.

Il flusso di esecuzione

WHILE: controllo in testa

DO: controllo in coda

Esempio WHILE: somma da 1 a N

Per N ≥ 0, calcoliamo somma = 1 + 2 + ... + N. Se N=0, il corpo non viene eseguito e il risultato resta 0.

leggi N
se N < 0 allora
    scrivi "N non valido"
altrimenti
    i ← 1
    somma ← 0
    while i ≤ N do
        somma ← somma + i
        i ← i + 1
    end while
    scrivi somma
fine se

Con N=4, dopo quattro iterazioni i=5: la condizione è falsa e il risultato è 10.

Esempio DO: validazione di un input

Il valore deve essere letto almeno una volta. Il ciclo continua mentre il dato è esterno a [a,b].

leggi a, b
se a > b allora
    scrivi "estremi non validi"
altrimenti
    do
        leggi x
    while x < a ∨ x > b
    scrivi x
fine se

Nella figura Do di Flowgorithm si inserisce la condizione di continuazione x < a ∨ x > b. Con la notazione repeat-until si scriverebbe invece until x ≥ a ∧ x ≤ b.

Correttezza e terminazione

  1. Prima del ciclo: inizializza tutte le variabili lette dalla condizione o dal corpo.
  2. Durante il ciclo: verifica che il corpo mantenga corretto lo stato già costruito.
  3. Verso l'uscita: individua una quantità che cambia a ogni iterazione e raggiunge un limite.
  4. Dopo il ciclo: usa la condizione falsa per capire che cosa è ormai garantito.

Controlla sempre il caso in cui il WHILE esegue zero iterazioni e quello in cui il DO ne esegue esattamente una.

Esercizio 1 — Somma dei primi N interi

Leggi un intero N ≥ 0 e calcola la somma da 1 a N usando WHILE. Rifiuta i valori negativi.

leggi N
se N < 0 allora
    scrivi "N non valido"
altrimenti
    i ← 1
    somma ← 0
    while i ≤ N do
        somma ← somma + i
        i ← i + 1
    end while
    scrivi somma
fine se

Esercizio 2 — Numero di cifre

Leggi un intero n ≥ 0 e conta le sue cifre decimali. Ricorda che zero ha una cifra.

leggi n
se n < 0 allora
    scrivi "n non valido"
altrimenti se n = 0 allora
    scrivi 1
altrimenti
    cifre ← 0
    while n > 0 do
        n ← Int(n / 10)
        cifre ← cifre + 1
    end while
    scrivi cifre
fine se

Ogni divisione intera per 10 elimina l'ultima cifra e avvicina n a zero.

Esercizio 3 — Lettura nell'intervallo

Dati due estremi validi a ≤ b, continua a chiedere un intero finché ne viene inserito uno appartenente a [a,b]. Usa DO.

leggi a, b
do
    leggi x
while x < a ∨ x > b
scrivi x

Il ciclo ripete per i dati non validi e termina appena la condizione diventa falsa.

Esercizio 4 — Somma fino al valore sentinella

Leggi numeri interi e sommali. Il valore 0 conclude l'inserimento e non deve essere aggiunto.

somma ← 0
do
    leggi x
    se x ≠ 0 allora
        somma ← somma + x
    fine se
while x ≠ 0
scrivi somma

Sequenza di prova: 5, -2, 4, 0 produce 7. Il primo valore può essere subito zero.

Checklist

  • La condizione esprime chiaramente quando continuare?
  • Tutte le variabili hanno un valore prima del primo utilizzo?
  • Il corpo modifica almeno un valore rilevante per l'uscita?
  • WHILE funziona anche con zero iterazioni?
  • DO funziona anche quando basta una sola iterazione?
  • Hai tracciato a mano almeno le prime due iterazioni e l'uscita?
