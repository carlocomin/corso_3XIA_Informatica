Lezione 5.3 — Ricerca, conteggi e frequenze

Obiettivo: cercare valori in un array, contare elementi che soddisfano una condizione e costruire un istogramma su un dominio limitato.

Quattro domande, quattro risultati

DomandaRisultatoStrategia
Il valore esiste?BooleanArresta la scansione al primo elemento uguale.
Dove compare per la prima volta?Indice oppure -1Arresta la scansione alla prima occorrenza.
Dove compare per l'ultima volta?Indice oppure -1Scansiona tutto e aggiorna ogni volta.
Quante volte compare?Intero ≥ 0Scansiona tutto e incrementa un contatore.

La convenzione -1 indica «posizione non esistente», perché gli indici validi dell'array iniziano da zero.

Prima occorrenza con arresto anticipato

leggi x
posizione ← -1
i ← 0

while i < n ∧ posizione = -1 do
    se A[i] = x allora
        posizione ← i
    altrimenti
        i ← i + 1
    fine se
end while

se posizione = -1 allora
    scrivi "valore assente"
altrimenti
    scrivi "Prima posizione = " & posizione
fine se

L'accesso A[i] avviene nel corpo, raggiunto soltanto quando i < n. Non è necessario affidarsi allo short-circuit per proteggere l'indice.

Nel caso migliore viene confrontato soltanto A[0]; nel caso peggiore vengono esaminati tutti gli n elementi.

Ultima occorrenza e numero di occorrenze

Ultima posizione

ultima ← -1
per i da 0 a n-1, crescente, passo 1
    se A[i] = x allora
        ultima ← i
    fine se
fine per

Ogni nuova occorrenza sostituisce la posizione precedente.

Quante occorrenze

quante ← 0
per i da 0 a n-1, crescente, passo 1
    se A[i] = x allora
        quante ← quante + 1
    fine se
fine per

Il contatore viene incrementato per ogni elemento uguale.

Per trovare l'ultima occorrenza o contare tutte le occorrenze non bisogna fermarsi al primo risultato.

L'elemento in posizione 3 non viene esaminato: l'obiettivo richiede la prima occorrenza.

Contare con un predicato

Il pattern del conteggio non è limitato all'uguaglianza. Per esempio, possiamo contare i valori appartenenti all'intervallo chiuso [10,20].

quanti ← 0
per i da 0 a n-1, crescente, passo 1
    se A[i] ≥ 10 ∧ A[i] ≤ 20 allora
        quanti ← quanti + 1
    fine se
fine per
scrivi "Valori in [10,20] = " & quanti

Dopo aver esaminato A[i], il contatore rappresenta quanti elementi da A[0] ad A[i] soddisfano la condizione.

Array delle frequenze

Se i valori ammessi appartengono a un dominio piccolo, per esempio i voti interi da 0 a 10, l'indice di un secondo array può rappresentare direttamente il valore contato.

Indice v012...910
freq[v]numero di 0numero di 1numero di 2...numero di 9numero di 10

Prima di usare freq[A[i]] bisogna verificare che A[i] sia un indice valido, cioè compreso tra 0 e 10.

Costruzione dell'istogramma

dichiara Integer freq[11]

per valore da 0 a Size(freq)-1, crescente, passo 1
    freq[valore] ← 0
fine per

validi ← 0
errori ← 0
per i da 0 a n-1, crescente, passo 1
    se A[i] ≥ 0 ∧ A[i] < Size(freq) allora
        freq[A[i]] ← freq[A[i]] + 1
        validi ← validi + 1
    altrimenti
        errori ← errori + 1
    fine se
fine per

per valore da 0 a Size(freq)-1, crescente, passo 1
    scrivi valore & ": " & freq[valore]
fine per
scrivi "Valori fuori dominio = " & errori

L'azzeramento è indispensabile: ogni cella deve partire da 0 prima che inizino gli incrementi.

Moda e parità di frequenza

La moda è il valore con frequenza massima. Se più valori raggiungono la stessa frequenza massima, sono tutti valori modali.

se validi = 0 allora
    scrivi "moda non definita: nessun dato valido"
altrimenti
    frequenzaMax ← freq[0]
    per valore da 1 a Size(freq)-1, crescente, passo 1
        se freq[valore] > frequenzaMax allora
            frequenzaMax ← freq[valore]
        fine se
    fine per

    scrivi "Valori modali:"
    per valore da 0 a Size(freq)-1, crescente, passo 1
        se freq[valore] = frequenzaMax allora
            scrivi valore
        fine se
    fine per
    scrivi "Frequenza = " & frequenzaMax
fine se

La guardia validi=0 impedisce di dichiarare come mode valori che hanno tutti frequenza zero.

Esercizio 1 — Prima e ultima occorrenza

Input
Array A, dimensione n e valore x.
Output
Prima e ultima posizione di x oppure un messaggio se x è assente.
Richiesta
Usare una sola scansione completa.
prima ← -1
ultima ← -1

per i da 0 a n-1, crescente, passo 1
    se A[i] = x allora
        se prima = -1 allora
            prima ← i
        fine se
        ultima ← i
    fine se
fine per

se prima = -1 allora
    scrivi "valore assente"
altrimenti
    scrivi "Prima = " & prima
    scrivi "Ultima = " & ultima
fine se

Esercizio 2 — Conteggio per fasce

Input
Array di interi A.
Fasce
0–4, 5–9, 10–14, almeno 15; i valori negativi sono non validi.
Output
Numero di elementi in ogni fascia e numero di errori.
fascia04 ← 0
fascia59 ← 0
fascia1014 ← 0
fascia15 ← 0
errori ← 0

per i da 0 a n-1, crescente, passo 1
    se A[i] < 0 allora
        errori ← errori + 1
    altrimenti se A[i] < 5 allora
        fascia04 ← fascia04 + 1
    altrimenti se A[i] < 10 allora
        fascia59 ← fascia59 + 1
    altrimenti se A[i] < 15 allora
        fascia1014 ← fascia1014 + 1
    altrimenti
        fascia15 ← fascia15 + 1
    fine se
fine per

Come controllo deve valere fascia04 + fascia59 + fascia1014 + fascia15 + errori = n.

Esercizio 3 — Quanti valori distinti e quali mode?

Input
Array delle frequenze freq[11] già costruito e almeno un dato valido.
Output
Numero di valori distinti presenti e tutti i valori con frequenza massima.
distinti ← 0
frequenzaMax ← 0

per valore da 0 a Size(freq)-1, crescente, passo 1
    se freq[valore] > 0 allora
        distinti ← distinti + 1
        se freq[valore] > frequenzaMax allora
            frequenzaMax ← freq[valore]
        fine se
    fine se
fine per

scrivi "Valori distinti = " & distinti
scrivi "Mode:"
per valore da 0 a Size(freq)-1, crescente, passo 1
    se freq[valore] = frequenzaMax allora
        scrivi valore
    fine se
fine per

Checklist

  • Ho scelto tra arresto anticipato e scansione completa in base all'obiettivo?
  • Il valore -1 è usato soltanto come indice non valido?
  • Il contatore parte da zero?
  • L'array delle frequenze viene azzerato prima del conteggio?
  • Controllo il dominio prima di usare un dato come indice?
  • Gestisco il caso con zero dati validi e quello con più mode?
