Lezione 5.2 — Somma, media, minimo e massimo

Obiettivo: ottenere informazioni da un array con una scansione, mantenendo accumulatori, valori candidati e relativi indici.

Precondizioni della scansione

  • L'array A è già stato caricato nelle celle da A[0] ad A[n-1].
  • La dimensione logica rispetta 0 ≤ n ≤ Size(A).
  • La somma di un array vuoto può essere definita come 0.
  • Media, minimo e massimo richiedono n ≥ 1.

Negli esempi principali imponiamo n ≥ 1, così è sempre possibile leggere A[0].

Il pattern dell'accumulatore

Un accumulatore conserva il risultato parziale costruito durante la scansione.

somma ← 0
per i da 0 a n-1, crescente, passo 1
    somma ← somma + A[i]
fine per

Dopo l'iterazione con indice i, somma contiene la somma degli elementi da A[0] ad A[i].

Il valore iniziale dipende dall'operazione: 0 per una somma, 1 per un prodotto, 0 per un conteggio.

Somma e media

se n = 0 allora
    scrivi "media non definita"
altrimenti
    somma ← 0
    per i da 0 a n-1, crescente, passo 1
        somma ← somma + A[i]
    fine per
    media ← somma / n
    scrivi "Somma = " & somma
    scrivi "Media = " & media
fine se

In Flowgorithm l'operatore / produce una divisione reale anche quando gli operandi sono interi. Nella futura traduzione in C o C++ sarà invece necessario controllare i tipi degli operandi.

La guardia su n=0 evita una divisione per zero e segnala che la media di un insieme vuoto non è definita.

Minimo e massimo: inizializzare con un dato reale

Non inizializzare minimo o massimo con 0: questo valore potrebbe non appartenere all'array e produrre un risultato sbagliato. Con n ≥ 1, il primo elemento è un candidato sempre valido.

Minimo con indice

minimo ← A[0]
indiceMin ← 0
per i da 1 a n-1, crescente, passo 1
    se A[i] < minimo allora
        minimo ← A[i]
        indiceMin ← i
    fine se
fine per

Massimo con indice

massimo ← A[0]
indiceMax ← 0
per i da 1 a n-1, crescente, passo 1
    se A[i] > massimo allora
        massimo ← A[i]
        indiceMax ← i
    fine se
fine per

Usando confronti stretti < e >, in caso di valori uguali viene mantenuto l'indice della prima occorrenza.

Prima o ultima occorrenza dell'estremo?

ObiettivoConfronto per il minimoConfronto per il massimoEffetto in caso di parità
Prima occorrenza<>Un valore uguale non sostituisce il candidato.
Ultima occorrenza≤≥Un valore uguale aggiorna l'indice.

Somma, minimo e massimo in una sola scansione

Con n ≥ 1 si può inizializzare tutto dal primo elemento e continuare da i=1.

somma ← A[0]
minimo ← A[0]
massimo ← A[0]
indiceMin ← 0
indiceMax ← 0

per i da 1 a n-1, crescente, passo 1
    somma ← somma + A[i]

    se A[i] < minimo allora
        minimo ← A[i]
        indiceMin ← i
    fine se

    se A[i] > massimo allora
        massimo ← A[i]
        indiceMax ← i
    fine se
fine per

media ← somma / n

Una sola scansione riduce il numero di accessi all'array. Scansioni separate possono comunque essere preferibili quando rendono più chiaro un problema complesso.

Esercizio 1 — Media dei soli positivi

Input
Array reale A già caricato, con n ≥ 0.
Output
Somma e media degli elementi positivi; un messaggio se non ne esistono.
sommaPos ← 0
quantiPos ← 0

per i da 0 a n-1, crescente, passo 1
    se A[i] > 0 allora
        sommaPos ← sommaPos + A[i]
        quantiPos ← quantiPos + 1
    fine se
fine per

se quantiPos = 0 allora
    scrivi "nessun valore positivo"
altrimenti
    mediaPos ← sommaPos / quantiPos
    scrivi "Somma = " & sommaPos
    scrivi "Media = " & mediaPos
fine se

Esercizio 2 — Secondo massimo distinto

Input
Array reale A con n ≥ 1.
Output
Il massimo e il più grande valore strettamente minore del massimo, con i rispettivi indici.
Caso limite
Il secondo massimo non esiste se tutti i valori sono uguali.
massimo ← A[0]
indiceMax ← 0
indiceSecondo ← -1

per i da 1 a n-1, crescente, passo 1
    se A[i] > massimo allora
        secondo ← massimo
        indiceSecondo ← indiceMax
        massimo ← A[i]
        indiceMax ← i
    altrimenti se A[i] < massimo allora
        se indiceSecondo = -1 allora
            secondo ← A[i]
            indiceSecondo ← i
        altrimenti se A[i] > secondo allora
            secondo ← A[i]
            indiceSecondo ← i
        fine se
    fine se
fine per

scrivi "Massimo = " & massimo & " in posizione " & indiceMax
se indiceSecondo = -1 allora
    scrivi "secondo massimo non esistente"
altrimenti
    scrivi "Secondo = " & secondo & " in posizione " & indiceSecondo
fine se

La variabile secondo viene letta soltanto dopo che indiceSecondo ha smesso di valere -1; non si dipende dalla valutazione cortocircuitata.

Esercizio 3 — Pari e dispari

Input
Array di interi A con n ≥ 0.
Output
Numero di elementi pari e dispari.
pari ← 0
dispari ← 0

per i da 0 a n-1, crescente, passo 1
    se Abs(A[i]) mod 2 = 0 allora
        pari ← pari + 1
    altrimenti
        dispari ← dispari + 1
    fine se
fine per

scrivi "Pari = " & pari
scrivi "Dispari = " & dispari

Come controllo finale deve valere pari + dispari = n.

Checklist

  • Ho controllato n=0 prima di calcolare media, minimo o massimo?
  • L'accumulatore parte dal valore neutro corretto?
  • Minimo e massimo sono inizializzati con A[0]?
  • Aggiorno sempre insieme valore e indice?
  • Ho deciso esplicitamente come gestire gli elementi uguali?
  • Ho provato array con un elemento, tutti uguali, tutti negativi e valori ripetuti?
